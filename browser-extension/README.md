# 美客多 ERP 选品助手 - Chrome 扩展

## 安装方法

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目下的 `browser-extension` 文件夹
5. 扩展安装完成！

## 使用方法

### 在美客多网站
- 打开美客多任意站点（墨西哥、巴西等）
- 浏览商品详情页或列表页时，右下角会出现蓝色 📊 按钮
- 点击按钮，商品数据会自动推送到 ERP
- 或在扩展弹窗中点击「推送当前页商品」

### 在 1688 网站
- 打开 1688 商品详情页
- 点击右下角按钮或扩展弹窗中的按钮
- 供应商信息会推送到 ERP 辅助比价

### 在 ERP 中查看
- 进入「热销榜选品 → 扩展采集」标签页
- 查看已采集商品和自动评分结果

## 功能特点
- ✅ 自动识别美客多/1688页面
- ✅ 一键推送商品数据
- ✅ 列表页批量采集
- ✅ 自动同步到 ERP 选品评分
